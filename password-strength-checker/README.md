# Password Strength Checker

A command-line utility written in Python that evaluates password security based on multiple criteria including length, numbers, uppercase letters, lowercase letters, and special characters.

## Features

- **Length Validation**: Checks if the password meets the 8-character minimum requirement.
- **Character Composition Checks**: Verifies the presence of numeric digits, uppercase letters, lowercase letters, and standard punctuation.
- **Scoring System**: Adds or subtracts points based on fulfilled criteria to output a final security score.

```text
